# Documentation Skill

## Purpose
Synthesize clear, complete, and accurate technical documentation, API specifications, and architecture decision records based on verified codebase evidence.

## Execution Procedure
1. Inspect public APIs, function signatures, and docstrings.
2. Verify system architecture and configuration options.
3. Generate or update markdown documentation adhering to documentation guidelines.
4. Validate that all generated code snippets are syntactically valid and tested.
